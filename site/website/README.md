# Site vitrine PsyConnect

Site statique de présentation de PsyConnect, avec trois questionnaires d'auto-évaluation qui s'exécutent entièrement dans le navigateur.

- `index.html` : présentation de l'application
- `tests.html` : questionnaires et résultats
- `mentions.html` : mentions légales et protection des données
- `assets/` : styles, scripts, police Figtree et images

Aucune dépendance ni étape de build : il suffit d'ouvrir `index.html`. Le site n'est pas encore en ligne.
