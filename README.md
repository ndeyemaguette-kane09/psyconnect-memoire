# PsyConnect, documents du mémoire

Dépôt privé qui accompagne le code de l'application ([psyconnect](https://github.com/ndeyemaguette-kane09/psyconnect)).

- `docs/redact` : mémoire, diagrammes, captures, fiches de préparation
- `docs/Fils_Rouges` : fiches de révision par fonctionnalité
- `docs/etude_utilisateurs` : kit du test d'utilisabilité
- `presentation` : diapositives de soutenance
- `captures` : captures d'écran par interface (patient, psychologue, administrateur)
- `postman` : collections de tests d'API
- `site` : site vitrine statique
- `logos`, `diplomes_factices` : images utilisées dans le mémoire et pour les tests

Les vidéos de démonstration sont trop lourdes pour GitHub et restent hors dépôt.
